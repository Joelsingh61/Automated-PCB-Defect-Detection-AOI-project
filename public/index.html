01 — Project Overview

Replacing manual PCB inspection with AI-powered vision

Printed circuit boards contain tiny defects that can affect electrical performance and manufacturing quality. Manual inspection is time-consuming and can be inconsistent. This project explores an automated computer-vision approach capable of detecting and localizing PCB defects.

!

The Problem

Manual PCB inspection requires time, skilled operators and can miss small or visually complex defects.

AI

The Solution

A YOLO-based object detection model identifies PCB defects directly from inspection images and produces bounding boxes with confidence scores.

✓

Industrial Impact

Automated inspection can support faster quality checks, defect localization and more consistent inspection workflows in electronics manufacturing.

03 — Defect Classification

Six PCB defects. One vision system.

DETECTED

Open

Broken or disconnected conductive trace.

Short

Unintended connection between conductive paths.

Mousebite

Irregular edge damage resembling bite marks.

Spur

Unwanted copper extension from a conductive trace.

Pin-hole

Small unwanted hole or void in the PCB structure.

Spurious Copper

Unwanted copper remaining in non-conductive regions.

04 — Detection Pipeline

From PCB image to defect decision

The complete workflow combines image processing, deep learning and object detection.

01

Input PCB Image

A PCB inspection image is provided to the computer vision pipeline. The image acts as the input for automated quality inspection.

02

Image Processing

Python and OpenCV are used as part of the computer vision workflow for preparing and handling the inspection images.

03

YOLO26n Inference

The trained YOLO26n object-detection model processes the image and predicts defect classes, locations and confidence scores.

04

Bounding Box Localization

Each detected defect is localized using a bounding box, allowing the inspection system to identify exactly where the defect occurs on the PCB.

05

Inspection Result

The final output contains the defect class, bounding-box location and confidence score, providing an interpretable automated inspection result.
